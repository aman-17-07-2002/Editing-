# Aman Kumar - Video Editor & Visual Storyteller Portfolio

A modern, clean, and aesthetic 1-page Video Editor Portfolio web application built with **React**, **Tailwind CSS**, **Lucide React**, and **Framer Motion**.

---

## 🎬 Highlights & Features

- **Dark Minimal Aesthetic**: Sleek slate/zinc color palette with subtle indigo and purple ambient lighting.
- **Hero Section**: Smooth animated typography, tagline, subtitle, and primary call-to-actions.
- **About & Education**: Clean cards highlighting narrative pacing and academic background at **G. L. Bajaj Institute of Technology & Management (MCA)**.
- **Tools & Skills**: Visual badges showcasing daily drivers (**CapCut**, **VN Video Editor**, **Canva**, **Adobe Photoshop**, and **Premiere Pro**) plus key retention strengths.
- **Featured Drive Showcase**: Dedicated Google Drive repository hub covering YouTube Long-form edits, Shorts/Reels, and Thumbnail designs.
- **Contact & Footer**: Quick email launch, 1-click clipboard copy with instant visual confirmation, and Google Drive links.
- **Framer Motion**: Subtle entrance fade-ins and interactive card/button hover lifts.
- **Fully Responsive**: Optimized for smartphones, tablets, laptops, and ultra-wide displays.

---

## 🚀 How to Run Locally

1. **Install dependencies** (already installed in this workspace):
   ```bash
   npm install
   ```

2. **Start the local development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🔗 How to Update Your Google Drive Link

Open [`src/App.tsx`](file:///src/App.tsx) and update the `DRIVE_PORTFOLIO_LINK` constant at the top of the file:

```tsx
const DRIVE_PORTFOLIO_LINK = "https://drive.google.com/drive/folders/YOUR_REAL_FOLDER_ID";
```

All buttons across the portfolio ("View My Drive Edits", "Watch Samples on Google Drive", header, and footer) will automatically direct to your actual Drive folder.
